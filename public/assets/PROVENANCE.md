# Temporary character asset

This file documents the local prototype asset. The image itself is ignored by Git and is not included in the public repository. A fresh clone requires an authorised replacement matching the grid below before gameplay can start.

codex.webp is an unchanged copy of the bundled Codex pet sheet:
`/Applications/ChatGPT.app/Contents/Resources/app.asar/webview/assets/codex-spritesheet-v6-51045ae208c0.webp`.

Used at the user's request for the local prototype. Not an assertion of redistribution rights; replace or resolve rights before a public release. The original grid is 8 columns by 11 rows, 192 × 208 pixels per cell. Walking, idle, jump and outcome frames are selected at runtime. Scenery is original code-generated pixel artwork in src/game/art.ts. Fonts are bundled from Fontsource with their licences.
