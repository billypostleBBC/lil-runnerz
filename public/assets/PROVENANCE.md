# Character asset provenance

## Bill-e Bot

`bill-e-bot.png` is a validated custom animated pet sprite sheet created from a contributor-provided face reference for this repository. The contributor authorised its use here. The original reference photograph is not included. This record does not claim rights beyond that permission.

The PNG is 1536×2288 with transparency. Its animated v2 grid is 8 columns by 11 rows, 192×208 pixels per cell, covering nine animation states and sixteen look directions. Walking, idle, jump and outcome frames are selected at runtime.

## Codex

The temporary `codex.webp` image is ignored by Git and is not included in the public repository. Its character entry remains selectable only when an authorised local copy exists.

codex.webp is an unchanged copy of the bundled Codex pet sheet:
`/Applications/ChatGPT.app/Contents/Resources/app.asar/webview/assets/codex-spritesheet-v6-51045ae208c0.webp`.

Used at the user's request for the local prototype. Not an assertion of redistribution rights; replace or resolve rights before a public release. The original grid is 8 columns by 11 rows, 192×208 pixels per cell.

Scenery is original code-generated pixel artwork in `src/game/art.ts`. Fonts are bundled from Fontsource with their licences.

## Marty McFly

`marty.png` is newly hand-authored pixel artwork generated by `scripts/marty-sprite.py`, using rectangles on a 64 × 80 grid. Fourteen frames cover breathing, running with arm swings, take-off, tuck, descent, landing, hoverboard, defeat and victory. The user supplied a photographic shoe reference for grey high-tops, white straps and cyan soles; the sprite is drawn in code. It contains no copied film artwork or Codex pet pixels. Character concept and hoverboard supplied by the user; see `docs/marty.md` for the brief and implemented rules.
