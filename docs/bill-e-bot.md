# Bill-e Bot — rocket boots

Updated 9 October 2026: rocket boots replace Bill-e Bot's shield. This is his only power. Codex retains the shield; Marty retains the hoverboard.

Press Left Shift to apply one immediate upward impulse, setting vertical velocity to -360 px/s unless an existing jump is already moving upwards faster. This does not add velocities together. Normal gravity applies immediately afterwards; holding the key does not create sustained thrust. From rest, the impulse has a nominal 72px rise under the existing 900px/s² gravity. Using it near a jump's apex extends that jump. The 220ms boot plume is feedback only, not continuing propulsion.

A four-second cooldown starts on activation. Landing is also required before another activation, even if the cooldown expires during a long fall. Pausing freezes the cooldown; a new run resets it. The HUD displays rearming requirements. The normal 160px/s speed and 410px/s jump are unchanged.

Boots provide no immunity to flames, spikes, spiders, snakes, pits or water forces. Waterfalls still force descent after a boost. Autonomous play uses the same activation function as manual play: it jumps active flames and looks for a boost near the apex on a bonus route, over a gap or before descending onto a flame. It avoids firing directly into a low ceiling. The controller can still fail; this is not invulnerability or a guarantee of completion.
